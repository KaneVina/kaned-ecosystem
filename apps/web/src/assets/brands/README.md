# Logo nhà cung cấp đăng nhập

Nút "Tiếp tục với Google / Microsoft / GitHub / Facebook" hiện chữ cái đầu khi chưa có logo.
Muốn hiện logo chính thức, tải từ bộ nhận diện của từng hãng rồi đặt vào thư mục này với đúng tên:

- `google.svg`
- `microsoft.svg`
- `github.svg`
- `facebook.svg`

Vite tự nhận các tệp này khi build; không cần sửa code. Dùng đúng logo và màu theo hướng dẫn thương hiệu
của từng hãng.
